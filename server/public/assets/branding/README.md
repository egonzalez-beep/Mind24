# Branding — Mind24 Assess

Coloca aquí el logo oficial de Mind24 para reportes PDF.

## Archivo esperado (uno de los dos)

- `mind24-logo.svg` (recomendado: horizontal, fondo transparente)
- `mind24-logo.png` (alternativa)

## Proporciones recomendadas

- Orientación horizontal o compacta
- Altura visual objetivo: ~32–40 px en la portada del PDF
- Ancho máximo reservado en layout: ~180 px (no debe desbordar el encabezado)

El motor de reportes detecta automáticamente el archivo al generar el PDF.
Si no existe, se muestra un placeholder discreto hasta que se agregue el logo real.
